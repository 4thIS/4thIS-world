# 발소리 파일 (Kenney "Impact Sounds", CC0)

https://kenney.nl/assets/impact-sounds 에서 받은 묶음의 `Audio/` 폴더에서 아래 15개를 이 폴더에 그대로 넣는다.

- `footstep_concrete_000.ogg` ~ `footstep_concrete_004.ogg` — 길·광장·테라스
- `footstep_grass_000.ogg` ~ `footstep_grass_004.ogg` — 잔디
- `footstep_wood_000.ogg` ~ `footstep_wood_004.ogg` — 건물 안 (계단은 조금 높게)

라이선스: CC0 (저작자 표시 없이 사용 가능). 파일이 없으면 합성 발소리로 낸다 (`src/sound/steps.ts`).
