# 조작법 힌트 오버레이 설계

- 작성일: 2026-10-29 · 상태: 승인됨(팀장) · 구현: 박찬우(`cw`) 한 PR

| 항목 | 내용 |
|---|---|
| 언제 | 소개 모달을 닫으면(구경하기·가입·✕) 뜬다. 가입을 골랐으면 가입 흐름이 다 닫힌 뒤. UI 스토어 `guideAfterClose`로 예약하고 `close()`가 `'guide'`를 연다. 소개 모달처럼 "오늘 하루 보지 않기"면 그날은 안 뜬다. 상단 바 `?`로 언제든 다시 연다 |
| 모양 | 반투명 어두운 배경 + 가운데 카드 3장(왼쪽 드래그 돌리기 · 오른쪽 드래그 옮기기 · 휠 확대·축소, CSS 애니메이션) + 키보드 한 줄. 실제 버튼(🏠·접속자 패널·🎮 조종하기)을 가리키는 통통 튀는 말풍선. 버튼이 없으면 그 말풍선도 없다. 접속자 패널은 화면 위쪽이면 왼쪽에, 아래쪽(모바일 시트)이면 위에 |
| 터치 | `(pointer: coarse)`면 한 손가락·두 손가락·두 번 탭하고 끌기 카드, 키보드 줄 없음 |
| 닫기 | 아무 곳 누르기·아무 키·휠·"알겠어요". 그 입력은 캡처 단계에서 멈춰 월드(카메라·Esc)로 넘기지 않는다 |
