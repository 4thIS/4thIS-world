# 모션 버튼 설계

- 작성일: 2026-10-30 · 상태: 승인됨(팀장, 지속 A · 사용 범위 C) · 구현: 박찬우(`cw`) 한 PR

## 모션 8개

🙌 만세(두 팔 번쩍 + 콩콩) · 👋 손 흔들기 · 😴 눕기 · 🎆 폭죽(두 팔 들고 머리 위 파스텔 불꽃 두 번) · 💃 춤(한 바퀴 돌며 흔들기) · 🙇 인사 · 🤸 점프 · 👏 박수

## 규칙

- 눕기만 계속(다른 행동을 할 때까지), 나머지는 2.6초 하고 원래 자세로 (앞 0.2초·뒤 0.25초 부드럽게)
- 언제든 쓸 수 있다(조종 중이 아니어도). 앉아 있으면 앉은 채로 팔 동작, 춤·인사·점프·눕기는 그 자리에서 일어서서(눕기는 바닥에)
- 눕기가 끝나는 때: 다른 모션을 고를 때, 조종으로 움직일 때, 조종을 놓을 때, 그 멤버의 마지막 탭이 닫힐 때(서버), 누운 자리에서 0.8 m 넘게 벗어날 때(시간표대로 걷기 시작 등, 화면)
- 로그인한 멤버·관리자만, 초당 1회

## 전달

소켓 `motion { kind, pos }` → 모두에게 `motion { memberId, kind, pos, at }`, 끝낼 때 `kind: null`. 서버는 눕기만 기억했다가 새로 접속한 소켓에 보낸다.

## 화면

채팅 바 오른쪽 😊 옆에 🕺 모션 버튼. 누르면 위로 4×2 판(그림 + 이름)이 펼쳐지고 고르면 닫힌다.
