# 말풍선 채팅·대사음 설계

- 작성일: 2026-10-30 · 상태: 승인됨(팀장) · 구현: 박찬우(`cw`) 한 PR

## 보내기

- 이모지 바 옆 입력칸("한마디… Enter"). 로그인한 멤버·관리자만 보인다
- 아무 데서나 Enter → 입력칸, Enter로 보내기, Esc로 비우고 빠져나오기. 한글 조합 중 Enter는 무시. 모달이 열려 있거나 다른 입력칸에 쓰는 중이면 단축키를 쓰지 않는다
- 30자(이모지 1자), 1초에 1번. 너무 빠르면 입력칸을 흔들어 알린다

## 전달 (서버, 저장 안 함)

소켓 `chat { text }` → 승인 멤버·관리자만, 멤버당 초당 1회(`SOCKET_LIMITS.chatPerSec`), `cleanChat`(공백·줄바꿈 정리, 1~30자), `maskProfanity`(흔한 욕설을 같은 길이의 `*`로, 글자 사이 공백·기호도 잡고 "시발점" 같은 말은 그대로) → 모두에게 `chat { memberId, text, at }`

## 말풍선

- 머리 위(이모지 높이, 이모지가 있으면 그 위) 흰 말풍선, 하나당 3초(뽁 나타나고 마지막 0.3초 흐려짐)
- 새 말풍선은 아래에, 이전 것은 위로. 각자 3초가 끝나면 사라져 위(오래된 것)부터 사라진다. 한 사람 최대 3개

## 대사음

- Web Audio로 글자마다 짧은 음(녹음 파일 없음). 공백은 쉼, 이모지·기호는 건너뜀, `?`로 끝나면 마지막 음을 올리고 `!`면 크고 빠르게
- 동물마다 기본 높이(오리 > 고양이 > 강아지 > 곰), 멤버마다 ±10%, 같은 글자는 같은 음
- 화면에 보이는 캐릭터만, 카메라와 가까울수록 크게(25 m 안 최대, 110 m에서 0)
- 기본 꺼짐. 상단 바 🔈/🔊로 켜고 브라우저에 기억. 켜 둔 채 다시 오면 첫 클릭·키 입력 때 깨운다(브라우저 자동 재생 정책)
