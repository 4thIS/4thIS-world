# 말풍선 채팅·대사음 설계

- 작성일: 2026-10-30 · 상태: 승인됨(팀장) · 구현: 박찬우(`cw`) 한 PR

## 보내기

- 이모지 바 옆 입력칸("한마디… Enter"). 로그인한 멤버·관리자만 보인다
- 아무 데서나 Enter → 입력칸, Enter로 보내기, Esc로 비우고 빠져나오기. 한글 조합 중 Enter는 무시. 모달이 열려 있거나 다른 입력칸에 쓰는 중이면 단축키를 쓰지 않는다
- 30자(이모지 1자), 1초에 1번. 너무 빠르면 입력칸을 흔들어 알린다

## 전달 (서버, 저장 안 함)

소켓 `chat { text }` → 승인 멤버·관리자만, 멤버당 초당 1회(`SOCKET_LIMITS.chatPerSec`), `cleanChat`(공백·줄바꿈 정리, 1~30자), `maskProfanity`(흔한 욕설을 같은 길이의 `*`로, 글자 사이 공백·기호도 잡고 "시발점" 같은 말은 그대로) → 모두에게 `chat { memberId, text, at }`

## 말풍선

- 머리 위(이모지 높이, 이모지가 있으면 그 위) 흰 말풍선, 하나당 3초(뽁 나타나고 마지막 0.3초 흐려짐)
- 새 말풍선은 아래에, 이전 것은 위로. 각자 3초가 끝나면 사라져 위(오래된 것)부터 사라진다. 한 사람 최대 3개

## 대사음 (2026-10-30 개정: 전자음 → 목소리 조각)

- 재료: 오픈소스 TTS **MeloTTS**(한국어, MIT)로 70글자(첫소리 묶음 ㄱㄴㄷㄹㅁㅂㅅㅇㅈㅎ × 모음 묶음 ㅏㅓㅗㅜㅡㅣㅔ)를 한 번 읽혀 0.25초 간격으로 붙인 `public/sound/voice.mp3`(약 64 KB). 만드는 법: `scripts/voice/README.md`
- 재생: 글자마다 비슷한 소리 조각(받침 무시, ㅋㅋ→크크, 영문·숫자도 비슷한 소리)의 앞부분을 0.075초씩, 빠르고 높게(재생 속도 = 높이) 잇는다. 같은 글자는 같은 높이로 살짝 오르내린다
- 동물마다 높이(오리 2.05 > 고양이 1.85 > 강아지 1.65 > 곰 1.3), 멤버마다 ±6%. `?`로 끝나면 마지막 글자를 높이고 `!`면 크고 빠르게
- 화면에 보이는 캐릭터만, 카메라와 가까울수록 크게(25 m 안 최대, 110 m에서 0)
- 기본 꺼짐. 상단 바 🔈/🔊로 켜면 그때 재료를 받는다. 켜 둔 채 다시 오면 첫 클릭·키 입력 때 깨운다(브라우저 자동 재생 정책)

## 채팅 기록 (2026-10-30 추가, 팀장 A안)

- 서버가 최근 채팅 100개(`CHAT_HISTORY_MAX`)를 **메모리에만** 두고, 접속하면 `chat:history`로 준다. DB에는 남기지 않아 서버를 다시 켜면(배포) 비워진다
- 채팅 바 줄 오른쪽 끝 ▲: 누르면 위로 반투명 창(최대 240px)이 펼쳐진다. 한 줄 = `시간 · 동물 얼굴 · 이름 · 내용`, 오래된 것부터, 최신이 맨 아래. 맨 아래를 보고 있으면 새 채팅을 따라 내려가고, 위를 읽는 중이면 그대로
- 닫혀 있을 때 새 채팅이 오면 ▲에 분홍 점. 열림 상태는 브라우저에 기억
- 구경꾼(채팅 바가 없는 사람)도 ▲만 보이고 기록을 볼 수 있다
