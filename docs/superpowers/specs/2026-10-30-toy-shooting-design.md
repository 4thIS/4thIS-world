# 장난감 쏘기 설계

- 작성일: 2026-10-30 · 상태: 팀장 요청(물총·눈덩이·광선총 모두, 관리자 켜기·끄기) · 구현: 박찬우(`cw`)

## 규칙

- 조종 중에만 쏜다. 관리자가 켜 둔 장난감 하나가 조종 버튼 옆에 나오고, 버튼이나 F 키로 쏜다
- 보는 방향으로 최대 12 m. 같은 층에서 지나가는 길 0.6 m 안의 가장 가까운 캐릭터가 맞는다 (쏜 사람 화면이 계산)
- 물총(14 m/s, 낮은 포물선, 물방울 셋)·눈덩이(11 m/s, 높은 포물선)·광선총(32 m/s, 곧은 분홍 빛줄기)
- 맞으면 1.3초 반응(점수 없음): 물총은 부르르, 눈덩이는 뒤로 휘청, 광선총은 빙글. 머리 둘레로 물방울·눈가루·반짝이가 튄다
- 멤버당 초당 3번

## 전달

소켓 `shot { weapon, from, dir, hit, dist }` → 서버는 켜짐·조종 중인 탭·횟수만 확인 → 모두에게 `shot { …, memberId, at }`

## 관리자 설정

오른쪽 위 관리자 메뉴 → **관리자 설정** (사이트 전체에 바로 반영, `settings.admin_settings`, `GET·PATCH /api/admin/settings`)

- **장난감 쏘기**: 끄기 / 💦 물총 / ❄️ 눈덩이 / ✨ 광선총 중 하나 (기본 물총). `/api/world`의 `features.weapon`. 서버도 켜 둔 장난감만 받는다
- **날씨**: 실제 날씨 / 맑음 / 흐림 / 비 / 눈. 고정하면 `/api/weather`가 그 날씨를 주고 `weather:changed`로 모두 다시 받는다
- **시간**: 실제 시각 / 원하는 시각(오늘 KST). 캠퍼스 시계를 그만큼 옮겨(`clockOffsetMs`) `/api/world`·소켓 `time`의 서버 시각에 더한다. 그 시각부터 흘러간다
