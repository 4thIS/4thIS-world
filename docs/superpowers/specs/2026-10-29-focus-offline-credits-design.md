# 조작 되돌리기·오프라인 목록·포커스 표시·제작자 설계

- 작성일: 2026-10-29 · 상태: 승인됨(팀장) · 구현: 박찬우(`cw`) 한 PR
- 앞선 설계: `2026-10-29-camera-controls-design.md` (A 지도식 조작을 되돌린다)

| 항목 | 내용 |
|---|---|
| 1. 조작 | `OrbitControls`로 되돌린다: 왼쪽 끌기 = 회전, 오른쪽 끌기 = 이동. 왼쪽을 **더블 클릭(350 ms·24 px 안)한 채로 끌면** 그동안만 이동(터치는 더블 탭 후 끌기). 범위 제한·커서 쪽 확대·키보드·🏠은 그대로 |
| 2. 오프라인 목록 | 접속자 패널 아래 `오프라인 N`(접기 가능, 기본 펼침). 시간표상 지금 위치를 흐리게 보여 주고 누르면 그 캐릭터로 간다. 관리자 캐릭터 제외. `PresencePanelProps.offline` 계약 추가 |
| 3. 포커스 표시 | 포커스된 캐릭터 머리 위(3.4 × 크기)·건물 지붕 위(+4.3 m)에 분홍 동그라미 ✓ 스프라이트가 둥둥 뜬다. 다른 물체에 가려지지 않는다. 내 캐릭터를 조종하는 동안에는 숨긴다. 건물 카메라는 표시가 보이게 조금 위(+2.5 m)를 본다 |
| 4. 제작자 | 소개 모달 아래 "만든 사람 · 박찬우 · 이우진 · 박효민 · 김태희" |
