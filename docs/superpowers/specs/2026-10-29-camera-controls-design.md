# 카메라 조작 개선 설계

- 작성일: 2026-10-29 · 상태: 승인됨(팀장) · 구현: 박찬우(`cw`) 한 PR

## 1. 목표

- 건물·캐릭터 포커스에서 나오면(Esc, ✕, 빈 곳 클릭) 처음 접속했을 때의 전체 시야로 부드럽게 돌아간다.
- 화면 조작을 지도처럼 편하게 만든다.

## 2. 동작

| 항목 | 내용 |
|---|---|
| 처음 시야로 | `useWorld.goHome()`: 건물·캐릭터 포커스와 층 숨김을 풀고 `homeNonce`를 올린다. `CameraRig`가 `OVERVIEW`로 날아간다. Esc·빈 곳 클릭·건물 패널 ✕·🏠 버튼이 모두 이것을 부른다 |
| A. 지도식 조작 | drei `MapControls`: 왼쪽 드래그 = 이동, 오른쪽 드래그 = 회전, 휠 = 확대. 터치: 한 손가락 = 이동, 두 손가락 = 확대·회전 |
| B. 범위 제한 | 거리 `MIN_DISTANCE 6` ~ `MAX_DISTANCE 90` m, 기울기 상한은 그대로. 바라보는 점(target)의 x·z를 캠퍼스 ±25 m 안으로 자르고 카메라도 같이 옮긴다 (`clampTarget`) |
| C. 커서 쪽으로 확대 | `zoomToCursor` |
| D. 키보드 | 조종 중이 아니고 모달이 없고 글자 입력 중이 아닐 때: WASD·화살표 = 카메라 기준 이동(속도는 거리에 비례), Q/E = 바라보는 점을 축으로 회전 |
| E. 🏠 버튼 | 상단 바에 `처음 시야로` 버튼 (`TopBarProps.onHome`) |
| 끼어들기 | 카메라가 날아가는 중에 사용자가 끌거나 키를 누르면 날아가기를 멈춘다. 키로 움직이면 캐릭터 따라가기도 푼다(조종 중 제외) |

## 3. 테스트

- 순수 함수: `clampTarget`, `keyPan`(키 → 바닥 이동량), `orbitY`(축 회전), 키 입력을 받아도 되는지(`acceptsCameraKeys`)
- 스토어: `goHome`이 포커스를 풀고 nonce를 올린다
- 포커스 해제 경로(Esc·빈 곳·✕)가 `goHome`을 부른다
- 상단 바 🏠 버튼
- 기존 E2E 통과
