# 동물·장식 추가와 꾸미기 미리보기 돌리기 설계

- 작성일: 2026-10-30 · 상태: 팀장 승인 · 구현: 박찬우(`cw`) · PR 2개로 나눈다

## PR 1. 꾸미기 미리보기 돌리기

- 기본은 지금처럼 천천히 한 방향(0.6 rad/s)으로 돈다
- 미리보기를 잡고 좌우로 끌면 끈 만큼(0.012 rad/px) 그 방향으로 돈다. 잡고 있는 동안은 저절로 돌지 않는다
- 놓으면 그 방향에서 2초 멈췄다가 다시 천천히 돈다
- 세로 스크롤은 막지 않는다(`touch-action: pan-y`)
- 계산은 순수 함수 `ui/customize/turntable.ts`(grab·drag·release·tick)로 빼서 테스트한다

## PR 2. 동물 4종과 장식 8개

기존 구조(동물마다 `parts/<동물>.tsx`, 장식은 `accessories/head·eyes·neck.tsx`)를 그대로 쓴다.
`look.ts`의 목록에 값을 더하기만 하므로 저장된 캐릭터는 바뀌지 않는다.

| 동물      | 생김새                                         | 기본 색       | 색 바꾸기                  |
| --------- | ---------------------------------------------- | ------------- | -------------------------- |
| 🐰 rabbit | 길게 선 귀, 작은 분홍 코, 동그란 꼬리          | 분홍빛 흰색   | 몸 전체                    |
| 🐼 panda  | 곰 몸에 검은 귀·눈 무늬·팔다리                 | 흰색          | 흰 부분만 (검은 무늬 고정) |
| 🦊 fox    | 뾰족한 귀와 주둥이, 흰 가슴, 끝이 흰 큰 꼬리   | 주황          | 몸 전체 (흰 부분 고정)     |
| 🐧 penguin | 흰 배, 짧은 날개, 노란 부리와 발              | 남색          | 몸 전체 (배는 흰색 고정)   |

- 머리: 👑 crown · 🌸 flowerPin(한쪽 귀 옆) · 🎓 gradCap(술) · 🎧 headphones. 토끼처럼 귀가 높은 동물은 동물마다 머리 장식 높이를 맞춘다
- 눈: 🥽 goggles (모자와 겹치지 않게 눈 위에 쓴다)
- 목: 👔 necktie · 🦸 cape(걸을 때 살짝 펄럭임) · 🎒 backpack(등). 목 칸이라 목도리와 가방은 함께 못 한다
- 꾸미기 칩·접속 목록 이모지·무작위 꾸미기에 자동으로 들어간다
- 확인: 목록·무작위 테스트, `?dev=characters`에서 새 동물 × 새 장식을 모두 입혀 스크린샷
