# 4thIS-world

> 동아리원들의 시간표가 살아 움직이는 작은 캠퍼스

4thIS 동아리원이 자기 **주간 시간표**와 **동물 캐릭터**를 등록하면, 파스텔 톤의 3D 캠퍼스에서 캐릭터들이
**지금 이 시각의 시간표대로** 돌아다니는 웹사이트입니다.

## 어떤 웹인가요

- 🗓️ **시간표 등록** — 강의·연구·도서관·외부 일정 같은 매주 반복되는 일정을 넣습니다.
- 🐶 **캐릭터 꾸미기** — 강아지·고양이·곰·오리 중에 고르고, 색과 모자·안경·스카프 같은 악세서리를 골라 꾸밉니다.
- 🏫 **시간표대로 움직이는 캠퍼스**
  - 강의 시간이면 공학관 강의실 자리에 앉아 노트북을 두드리고
  - 공강이면 공원을 산책하거나 카페에서 쉬고
  - 점심시간에는 본관 식당에서 밥을 먹고
  - 알바 같은 외부 일정이면 정문으로 나갔다가 끝나면 다시 들어옵니다.
- 👋 **같이 접속하면** — 누가 접속해 있는지 보이고, 내 캐릭터를 직접 움직이거나 이모지로 인사할 수 있습니다.

## 왜 만드나요

명지전문대학 교수학습센터의 **2026-2학기 AI-DEAS 학습동아리** 활동으로 만드는 팀 프로젝트입니다.

- Claude Code 같은 **에이전트형 AI에게 작업을 맡기고**, 그 결과를 검증하고 고치는 경험을 직접 해 보는 것
- MCP·Skills 같은 AI 도구를 설치하고 목적에 맞게 조합해 쓰는 것
- Git과 PR 코드 리뷰 위에 AI를 얹어 **네 명이 함께 하나의 결과물을 완성하는 것**

이 세 가지가 목표입니다. 그리고 결과물로는 "지금 우리 동아리원은 어디서 뭘 하고 있지?"를 한눈에, 그리고
귀엽게 볼 수 있는 웹을 남기고 싶었습니다.

## 개발

Node 24 이상이 필요합니다.

```bash
npm install
npm run dev        # 서버 :8080 + 웹 :5173 (http://localhost:5173)
```

| 명령                | 하는 일                                     |
| ------------------- | ------------------------------------------- |
| `npm run typecheck` | 모든 워크스페이스 타입 검사                 |
| `npm run lint`      | ESLint                                      |
| `npm run format`    | Prettier로 고치기 (`format:check`는 검사만) |
| `npm test`          | 모든 워크스페이스 테스트                    |
| `npm run build`     | 웹 빌드 (`apps/web/dist`)                   |

## 구조

| 경로                            | 내용                                          | 담당                    |
| ------------------------------- | --------------------------------------------- | ----------------------- |
| `packages/shared`               | 스키마·소켓 계약·캠퍼스 데이터·placement 엔진 | cw (캠퍼스 데이터는 hm) |
| `apps/server`                   | Fastify + Socket.IO + SQLite                  | wj                      |
| `apps/web/src/world/campus`     | 캠퍼스 3D                                     | hm                      |
| `apps/web/src/world/characters` | 캐릭터 3D                                     | th                      |
| `apps/web/src/world/sim`        | 시간표대로 움직이기·조종                      | cw                      |
| `apps/web/src/ui`               | 화면 UI                                       | th                      |

## 협업 규칙

- 개인 브랜치 `cw` · `wj` · `hm` · `th` → `main`으로 PR. 머지는 **Create a merge commit**
- 머지 뒤 다음 작업 전에 `git fetch origin && git merge origin/main`
- CI 통과 + 다른 멤버 1명 승인. `packages/shared/src/schema`가 바뀌면 cw 승인 필수
